Code that runs in a child process (the agent worker in its sandbox, a script run by the Scripts dock or the scheduler) is not measured, and `models/` and `security/` are outside the measured roots.

## Features

Lines / branches: coverage of the feature's main modules together. Tests: test files that import one of them, and their test functions as happy / sad / edge (naming convention). E2E: hand-picked end-to-end tests, by kind:

- `ui`: the real window or widget offscreen (QTest keys/clicks or the slot a menu entry calls) on a real backend (LocalFS, RamFS)
- `backend`: the real backend on a real local resource (a folder, an SQLite file, a git repository, a FUSE mount, a real HTTP request against the served endpoint)
- `fake-server`: the backend's own wire code over a real socket against a protocol server scripted in the test
- `process`: a real axross child process (CLI, MCP server, watchdog)
- `lab`: a container of the podman lab (tests/docker); skipped when the lab is not reachable, so not part of a host coverage run

## How to refresh

1. Run every test file with branch coverage, one data file per test file:
   `cov_scope.sh <tree> <outdir> <list of tests/test_*.py>` (it writes `<outdir>/cov/.coverage.<file>` and `<outdir>/rc.txt`).
2. `coverage combine --keep --data-file=<outdir>/combined <outdir>/cov/.coverage.*`
3. `python scripts/coverage_matrix.py --data <outdir>/combined --rc <outdir>/rc.txt --command "..." --out docs/TEST_COVERAGE_MATRIX.md`
4. `python scripts/coverage_matrix.py --check` (also run by `tests/test_coverage_matrix_script.py`) fails when a feature names a module or an e2e test that no longer exists, or a new module belongs to no feature.
